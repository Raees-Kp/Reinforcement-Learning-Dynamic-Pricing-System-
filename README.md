# Reinforcement Learning for Dynamic Pricing System

## Overview

This project implements a Reinforcement Learning (RL) based Dynamic Pricing System for the Travel and Hospitality industry. The objective is to develop an intelligent pricing agent that learns optimal pricing strategies by interacting with a simulated market environment.

The RL agent adjusts prices based on factors such as remaining inventory and time until departure, with the goal of maximizing total revenue. The project compares the learned pricing policy against traditional pricing strategies to demonstrate the effectiveness of Reinforcement Learning for revenue optimization.
